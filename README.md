# Sailesh S - Portfolio Website 🚀

A stunning, modern, and highly interactive portfolio website built with React, TypeScript, Vite, and Tailwind CSS featuring advanced animations, particle effects, and dynamic content filtering.

## ✨ New Features

### 🎉 Animations & Visual Effects
- **Welcome Animation**: Eye-catching entrance animation with gradient text and icons
- **Particle Background**: Interactive particle system with connecting lines
- **Floating Elements**: Animated icons floating across the hero section
- **Gradient Animations**: Smooth color transitions on headings and buttons
- **Hover Effects**: Scale, rotate, and glow effects on interactive elements
- **Fade-in Animations**: Staggered entrance animations for all sections

### 🎨 Enhanced Components
- **Skills Section**: Color-coded skill badges with programming language-themed gradients
- **Projects Section**: 
  - Filter by category (All, Full Stack, Machine Learning, Frontend, Data Science)
  - Hover overlays with GitHub and live demo links
  - 6 featured projects with detailed information
  - Animated project cards with gradient borders
- **Stats Section**: Animated counters with floating icons and glow effects
- **Achievements**: Enhanced hackathon cards with gradient overlays
- **Hero Section**: Welcome message, gradient text, and animated call-to-action buttons

### 🎯 Interactive Features
- Project filtering system
- Smooth scroll navigation
- Responsive design for all devices
- Animated background elements
- Interactive particle system
- Hover state animations throughout

## 🚀 How to Run This App

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation & Setup

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run Development Server**
   ```bash
   npm run dev
   ```
   The app will open at `http://localhost:5173`

3. **Build for Production**
   ```bash
   npm run build
   ```
   The production files will be in the `dist` folder

4. **Preview Production Build**
   ```bash
   npm run preview
   ```
